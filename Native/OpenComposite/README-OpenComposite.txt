OpenComposite (openvr_api.dll in this folder)

An implementation of the OpenVR API on top of OpenXR, so the game can run on any OpenXR
runtime (SteamVR, Meta Quest Link / Air Link, Virtual Desktop, Monado, WiVRn, ...).
The UnRevive patcher installs it as the game's openvr_api.dll when Runtime > UseOpenXR is on.
